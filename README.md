# Chess Game 1 — v3.1 固定版

20×20 交錯棋盤上的兩人抽象棋。每一手只是「交換兩個相鄰棋子」，但被交換過的格子會**永久固化**，所以整盤棋是一場**一邊建設、一邊把棋盤鎖死**的競賽。你可以跟 BOT 對戰。

**單一 HTML 檔、零依賴、離線可用。**

---

## 快速開始

1. 用瀏覽器打開 `chess-game-1.html`（雙擊即可，不需要伺服器、不需要安裝任何東西）。
2. 右側「設定」選好 **BOT 難度** 與 **你執紅或藍** → 按 **開新局**。
3. 在棋盤上**點一格**，它所有可交換的鄰格會亮起外框 → **再點其中一格**完成交換。
   - 滑鼠移到目標格時會顯示**預覽**：交換後雙方分數，以及這一手對你自己的增減。
   - 按 `Esc`、或再點同一格，可取消選取。
   - 點到**不相鄰**的格子**不會成交**（只會把選取移到那一格），並會直接告訴你「不相鄰」。
4. 想不出手可以按 **跳過**（同樣算一手）。

> 設定（難度／執子／送勝條款）**只在按「開新局」時生效**，打到一半改動不會影響進行中的對局。

## 介面說明

| 區塊 | 內容 |
|---|---|
| **分數卡** | 紅、藍各自的分數、進度條（相對勝利門檻 500）、最大連通區格數 |
| **棋譜** | 每一手的方別、著手座標，以及該手之後的「紅分 / 藍分」；跳過會以斜體標示 |
| **開新局** | 依目前設定重新開始 |
| **跳過** | 放棄這一手，行棋權交給對手 |
| **悔棋（剩 N）** | 退回你上一手之前（含對手對你那一手的回應），整局最多 3 次 |
| **認輸** | 直接結束，對手獲勝 |
| **完整規則** | 頁面下方的可折疊區塊，與本文件規則一致 |

**棋盤上的顏色語言**

- 一般格子：紅／藍。
- **黑點**：該格已**永久固化**，雙方都不能再交換它。固化**不影響計分**，黑點格照樣算顏色、照樣算連通。
- 亮框：目前選取格的可交換鄰格。
- 選單裡的「標示全部可交換的格子」會把所有能動的格子都標出來（畫面較花，預設關閉）。

## 規則

### 1. 盤面

- 20×20 ＝ **400 格**，每格非紅即藍，交錯排列：**(橫＋縱) 為偶數 = 紅**。**紅方先手。**
- 座標顯示為 `(a, b)`：`a` 是橫向位置、`b` 是縱向位置，皆從 1 開始（與畫面完全一致）。
- 每一手只是「交換兩格內容」，所以**紅、藍棋子數永遠各 200 顆**，從頭到尾不變。
- 盤面沒有空格、沒有棋子編號，同色棋子完全不可區分。

### 2. 你的一手可以做什麼

- **交換**：選上下左右**相鄰**、**顏色相異**、且**兩格都尚未固化**的格子互換內容。
- **跳過（Pass）**：什麼都不做，直接把行棋權交給對手。跳過**同樣消耗一手**，雙方都能用、次數不限。
- **不合法**：同色相鄰互換（盤面不變，不算一手）、不相鄰、越界、任一格已固化。

### 3. 固化（本版核心）

- 被交換過的兩格**立即永久固化**，之後任何一方都不得再交換它們。這是那一手的一部分，不可省略。
- 固化**不影響計分**。
- 因為每手固定固化 2 格，固化集合只增不減 → **盤面狀態不可能重複**，所以本遊戲**不需要**「禁止重複盤面」規則。
- 開局時有 **760 組**合法交換，隨固化增加而遞減；理論上最多 200 手就會全部鎖死。

### 4. 計分

- **連通區域** ＝ 同色且以上下左右相連的最大格子集合（固化與否不影響）。
- **單色分數 ＝ Σ k·log₂k**，`k` 是該區域格數；`k = 1` 貢獻 0。**不做 floor、不四捨五入**，分數是小數。

| k | 1 | 2 | 3 | 4 | 8 | 9 | 16 | 20 | 32 | 80 | 200 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| k·log₂k | 0 | 2 | 4.75 | 8 | 24 | 28.5 | 64 | 86.4 | 160 | 505.8 | 1528.8 |

- **單色理論上限 1528.8**（200 顆全部連成一區）。
- `k·log₂k` 是凸函數且 `f(0)=0`，因此 **`f(a)+f(b) ≤ f(a+b)`（超可加）**：**拆開大區永遠不划算**，而且合併的邊際效益會隨區域變大而**上升**。這是本遊戲最重要的策略事實。
- 想靠**單一連通區**直接達標 500 分，需要約 **80 格**（80·log₂80 = 505.8）。
- 由於沒有 floor，只有 `k` 是 2 的次方時分數才會是整數；也因為如此，除了 0:0 之外，**精確同分幾乎不可能發生**。

### 5. 勝負（每一手結束後立即結算）

- **勝利門檻 T = 500**：分數達到 500 的一方**立刻獲勝**。
- 若一手同時讓雙方都達標 → **和局**。
- **送勝條款**（預設開啟，可關閉）：你的一手若只讓**對手**達標而自己未達標 → **對手勝**。關閉時只有落子方能為自己宣勝。
- **上限 120 手**（紅 60 + 藍 60）：第 120 手結束後強制結算，**比分數，高者勝，同分和局**。
- **自然終局**：若輪到你時盤面上已**完全不存在**合法交換，遊戲立即結束並比分數。

### 6. 悔棋（對局輔助，不是棋規）

- 整局最多 **3 次**。悔棋會退回到你上一手之前，**包含對手對你那一手的回應**。

### 7. 必讀：所有權只是敘述，不是限制

- 交換是**對稱操作** —— 對任何一組相鄰異色格，「紅方動紅子」與「藍方動藍子」造成的下一盤面**完全相同**。
- 所以「只能移動自己的棋子」在數學上**不構成任何限制**：雙方每一手的可選走法集合永遠相同。所有權只決定「你要為哪一色得分」。
- 結論：**你也可以直接點藍格來交換**，那是完全合法的走法，不是 bug。

## BOT 難度

| 難度 | 演算法 | 目標函數 |
|---|---|---|
| 隨機 | 完全隨機 | — |
| 簡單 | 45% 隨機；否則從前 8 名中隨機 | 競速 |
| 普通 | 1 手貪心（掃描全部合法手，約 40–80 ms） | 競速 |
| 困難 | 深度 2 maximin（前 8 手 × 對手所有回應，約 0.4–0.7 秒） | 競速 |
| 專家 | 深度 2 maximin | **壓制** |

- **競速**目標 ＝ `自己 − 0.03 × 對手`：專心養大自己的區，只用很小的權重干擾對手。
- **壓制**目標 ＝ `自己 − 對手`：直接最大化分差，會**主動拆你的連通區**，把雙方都磨成碎片。
- **BOT 的跳過政策**：只有當「每一手對自己都不利（值 ≤ 0）」時才會跳過，殘局常見；它**不會**用跳過來拖延時間。

**為什麼專家特別難打：** 因為所有權只是敘述（見規則 7），BOT 可以「動你的棋子」把你剛養出來的大區拆掉，同時把格子固化讓你無法修復。跟專家對局時，雙方最大連通區通常都停在 10–30 格，**500 分幾乎不可能達成**，實質勝負由 120 手上限的總分決定。

## 策略提示

1. **前期專心養一個主區。** 超可加性代表集中永遠贏分散；開局就在各處平均發展是最常見的輸法。
2. **每一手先問「這一手我自己會不會倒扣」。** 交換同時改變雙方分數，很多隨手的一手會讓自己掉分。
3. **防守要拆對手的區，不是拆自己的。** 如果一手讓分差變好、但自己掉超過 5 分，通常是在拆自己家。
4. **對上「專家」不要想著達標 500。** 目標改成「在 120 手內總分贏他」，並且避免長時間空轉（十幾手只拿一兩分是最致命的）。

## 實作備註

- **單一檔案**：HTML + CSS + JS 全部在 `chess-game-1.html` 內，無外部資源、無相依套件、無建置步驟。
- **不使用 Web Worker**（刻意設計），因此用 `file://` 雙擊開啟即可正常運作；BOT 思考時以 async 分片讓出主執行緒，畫面不會凍結（但深度 2 需要約 0.4–0.7 秒）。
- 計分為 400 格的洪水填充（flood fill），每次落子後重算。
- **相鄰判定用座標 `(x, y)`，不用索引差**：索引差 1 在換行處會繞到棋盤另一側（第 20 欄 ↔ 第 1 欄），這是 v3.1.1 修掉的 bug。點擊路徑另有第二道防線：`isLegalMove()` 要求該手必須真的出現在 `genMoves()` 的清單裡。

## 版本

**v3.1.1（修正版，2026-09-28）**：修正「**兩個不相鄰的格子也能互換**」的判定錯誤。舊版只檢查「兩格都未固化且顏色相異」，漏了相鄰條件，因此在畫面上點任意兩個隔很遠的異色空格都會成交；現在嚴格限制為上下左右相鄰，點到不相鄰的格子會顯示提示。**規則、計分、BOT 完全沒有改動**（v3.1 的棋譜重播結果逐位元相同）。

**v3.1 固定版**：n = 20；交換後兩格永久固化；`k·log₂k` 計分（無 floor）；勝利門檻 **T = 500**；上限 **120 手**（紅 60 + 藍 60）；可跳過（算一手）；悔棋 3 次；送勝條款可開關。
